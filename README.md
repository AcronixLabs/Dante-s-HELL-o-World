## Auxiliary Systems & Enterprise Over-Engineering

### 1. Optical Character Recognition (OCR) & GUI Blit

Why just print the assembled string when you can needlessly consume graphics pipelines?

1. **Character Aggregation**: The orchestrator captures the characters generated across all 12 sequential circle executions.
2. **Vector Synthesis**: An in-memory SVG vector markup document (`hello.svg`) is generated from scratch.
3. **Monospace Rasterization**: Pillow rasterizes the SVG into a high-contrast PNG bitmap with monospace font metrics.
4. **Optical Character Recognition**: Tesseract 5.0 OCR (`--psm 7`) reads the characters back from the pixels to ensure the computer believes what it just drew.
5. **Hardware Viewport Projection**: The verified OCR text is projected onto a hardware-accelerated Pygame viewport. If the display driver complains, headless framebuffers keep the machine humble.

### 2. Quantum Proof-of-Work Multilingual Ledger

Because no modern tech stack is complete without buzzwords, `scripts/quantum_multilingual_miner.py` streams greetings through a simulated 1-Qubit quantum register:

* **Bloch Sphere Rotations**: Applies Hadamard ($H$) and parameterized $U(\theta, \phi)$ gates keyed to ASCII codepoints to ensure quantum superposition.
* **Wavefunction Collapse**: Measures projective measurement probabilities ($P_0, P_1$) and relative phase angles:
  $$\Delta\phi = \arg(z_1) - \arg(z_0)$$
* **Proof-of-Work Mining**: Computes SHA-256 blocks (difficulty prefix `000` or `0000`) incorporating the quantum entropy header across:
  * **National Languages**: Standard global character encodings.
  * **Regional Dialects**: Local colloquial corpora (NYC Deadass, Hawaiian Pidgin, Geordie).
  * **Constructed & Fictional Universes**: Dune Chakobsa, Star Wars Mando'a, and Klingon.

## Local Execution & Setup

### Environment Prerequisites

* **Host Platform**: Linux (x86-64 architecture required; ARM chips cannot survive NASM kernel ABI syscall violence)
* **Python Runtime**: Python 3.10+
* **C++ Compiler**: GCC 12+ (capable of enduring C++20 `consteval` compile recursion)
* **Rust Toolchain**: `rustc` & `cargo` (stable)
* **.NET Runtime**: .NET 8.0 SDK
* **Assembler & Linker**: NASM & GNU Binutils (`ld`)
* **Statistical Engine**: R runtime (`Rscript`)
* **Vision & Fonts**: Tesseract OCR & monospace fonts (`tesseract-ocr`, `fonts-dejavu-core`)
* **Display Libraries**: SDL2 development libraries (`libsdl2-dev` for Pygame display surfaces)

The continuous integration pipeline runs on every push to main and strictly enforces our standards of madness:

1. **Zero Fallbacks**: Audits the execution output to ensure no cowardly fallback handlers were triggered (`assert "(fallback" not in stdout`). Either the esoteric toolchain works, or the build fails.

2. **Strict Verification**: Confirms that OCR and compilation emitted byte-for-byte `"Hello, World"`.
